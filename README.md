# credit-risk-classifier
A binary classification problem that let's a lender decide whether to approve a loan. Given an applicant's financial history and personal circumstances, predict whether the applicant will default or repay. 

Credit Default Risk Classifier Streamlit App. 
This Streamlit app allows users to explore and evaluate different machine learning models for predicting credit default risk. Users can upload their own datasets, view model performance metrics, and visualize ROC curves. The app is built using Streamlit and leverages pre-trained models saved in the `model/` directory. It provides an interactive interface for users to understand how different models perform on their data.
